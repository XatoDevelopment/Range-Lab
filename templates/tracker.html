❓ Ayuda

📊 Dashboard

Capital, depósitos/retiros, ROI, ITM, winrate, rachas y mejor/peor sesión. Los chips (Hoy, 7 días, Este mes, 📅 Rango) filtran solo las stats y el gráfico; no afectan al historial. El toggle FREEROLL: marcado = se muestran en las estadísticas; sin marcar = se ocultan de las stats de rentabilidad (ROI, ITM, winrate…) pero siguen sumando al capital real.

➕ Añadir torneo

Registra nombre, buy-in, reentradas, premio, posición, tipo, velocidad, sala (ACR / CoinPoker / otra), jugadores, fecha y notas. Las salas personalizadas se guardan y aparecen en el desplegable la próxima vez. El capital se actualiza en el servidor. Si el coste es 0, el tipo se marca como Freeroll automáticamente.

📜 Historial

Pulsa Filtrar para abrir el panel: Periodo (hoy, 7/30 días, rango personalizado), Tipo (torneos, depósitos, retiros) y Sala. Los filtros se combinan y no se pierden. Buscador por nombre, sala o notas. Exporta el listado filtrado a CSV. Editar o eliminar entradas.

🔄 Reiniciar todo

Borra todo el historial y el capital, dejando la app como nueva. Se encuentra en el menú lateral. Requiere doble confirmación.

📥 Importar / Exportar JSON

Desde el menú Datos y Backup puedes exportar un JSON con torneos, movimientos y capital. Al importar: si no hay datos (o desde la pantalla de bienvenida) se carga de cero; si ya hay datos, eliges sumar sin duplicados o reemplazar todo.

☁️ Sincronización

Tus datos se guardan de forma segura. Puedes acceder desde cualquier dispositivo con tu cuenta y todo estará sincronizado.
